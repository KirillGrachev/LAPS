## Install

Normal users: use `KMAruda.LAPS_2.2.0_x64-setup.exe`. The
`KMAruda.LAPS_2.2.0_x64_ru-RU.msi` is the MSI payload for enterprise
deployment. The `KMAruda.LAPS_2.2.0_windows-x64_portable.zip` runs without
installation. The WebView2 bootstrapper is embedded in the installer.

Upgrading from 2.1 keeps the settings and the audit journal: they are moved to
`%APPDATA%\KMAruda LAPS` on first launch.

## What changed

### Features

- **Native clipboard:** copying and clearing go through Rust (`arboard`), so
  WebView2 no longer shows the clipboard permission prompt. Auto-clear compares
  the value in the backend and never exposes arbitrary clipboard content to the
  page.
- **Window state:** size, position and maximized state are stored in
  `window.json` next to the configuration; a monitor that has been disconnected
  no longer sends the window off-screen.
- **Encrypted LAPS diagnostics:** the parser scans for definite and
  indefinite-length CMS, reports every candidate and both decrypt flags, tries a
  full `LogonUser(INTERACTIVE)` token when the network token is rejected, and
  derives the domain for short account names from the Base DN or LDAP URL.
- **Data directory:** `%APPDATA%\KMAruda LAPS` with a one-time migration from
  `%APPDATA%\com.kmaruda.laps`.
- **Interface:** unified typography scale, compact settings, smoother dialogs
  and menus; the minimum window height is 680 px.

### Fixes

- DST-ambiguous and nonexistent local deadlines are rejected instead of being
  written with a wrong offset.
- A failed data migration leaves no partial directory behind.
- The settings autosave no longer overwrites newer keystrokes; the saved
  language is applied on start-up; late search/rotation responses cannot
  restore a cleared password card; audit pagination de-duplicates boundary rows.
- Saving an unchanged configuration does not append a duplicate audit record,
  and the test-mode toggle is audited again.
- The audit folder button works before the first event creates `audit.log`.

### Internal

- `chrono` replaced by `time`; `arboard`, `rustix`, `url` and `tokio` updated.
- RustSec audit job and `.cargo/audit.toml` for the documented Linux-only
  advisories; Rust tests: 72, frontend tests: 22.
- `tauri-plugin-window-state` replaced by an in-process store; MSI/NSIS release
  pipeline unchanged.
