## Install

Normal users: use `KMAruda LAPS_2.1.0_x64-setup.exe`. The
`KMAruda LAPS_2.1.0_x64_ru-RU.msi` is the MSI payload for enterprise
deployment. The `KMAruda.LAPS_2.1.0_windows-x64_portable.zip` runs without
installation. The WebView2 bootstrapper is embedded in the installer.

## What changed

### Features

- **Native Active Directory transport:** sign-in, computer search and
  expiration changes run over LDAP (`ldap3`) with LDAPS or StartTLS, a simple
  bind or the current Windows session (SASL GSSAPI/SSPI). No PowerShell, RSAT
  or `tauri-plugin-shell` ([572e7a3](https://github.com/KirillGrachev/LAPS/commit/572e7a3)).
- **Encrypted Windows LAPS:** `msLAPS-EncryptedPassword` is decrypted through
  `lapsutil.dll!DecryptNormalMode` under a `LogonWithCredentials` token for the
  account entered at sign-in, with `NCryptUnprotectSecret` as the SSO fallback.
  The MS-ADA2 2.66 envelope and known size/timestamp variants are tolerated
  ([572e7a3](https://github.com/KirillGrachev/LAPS/commit/572e7a3)).
- **Password workflow:** the saved language is applied on start-up, the
  settings autosave no longer overwrites newer keystrokes, the connection test
  saves the draft first, late responses cannot restore a cleared card, the
  clipboard cleanup reports failures, and the audit pages de-duplicate
  ([e5ff030](https://github.com/KirillGrachev/LAPS/commit/e5ff030)).
- **Repository:** maintained documentation set, Code of Conduct, CI on Linux
  and Windows, CodeQL, dependency review, OSV, Dependabot and release
  automation
  ([2d8beef](https://github.com/KirillGrachev/LAPS/commit/2d8beef),
  [4b050ad](https://github.com/KirillGrachev/LAPS/commit/4b050ad),
  [fad8e36](https://github.com/KirillGrachev/LAPS/commit/fad8e36)).

### Fixes

- "Reset now" writes the current FILETIME instead of deleting the expiration
  attribute; mixed domains update both expiration attributes.
- The LDAP URL scheme is case-insensitive and `ldap://` is always upgraded to
  StartTLS before a credential leaves the process.
- The connection test uses the settings on screen, not the previously saved
  file, and the reveal state resets for a new password.

### Internal

- 70 Rust unit tests and 22 frontend tests; `fmt`, `clippy -D warnings` and
  `cargo test` on Linux and Windows.
- Version 2.1.0; the configuration format stays compatible and contains no
  secrets.
