# Support

- **Bug or feature request:** open an issue using the templates.
- **Deployment, AD permissions, TLS:** read [ADMIN.md](ADMIN.md) and
  [TROUBLESHOOTING.md](TROUBLESHOOTING.md) first, then ask in
  [Discussions](https://github.com/KirillGrachev/LAPS/discussions).
- **Security vulnerability:** use
  [private vulnerability reporting](https://github.com/KirillGrachev/LAPS/security/advisories/new),
  never a public issue. See [SECURITY.md](SECURITY.md).

When reporting a problem, include the application version, the Windows build,
the error code, the decrypt diagnostic (it contains no password) and the steps
to reproduce. Remove domain names, computer names, account names and any
password from screenshots and logs.

There is no commercial support or SLA. This is an internal KMAruda tool
published as source; the maintainer answers on a best-effort basis.
